# Demo Guide

## Quick Start

### 1. Start Services

Terminal 1: ChromaDB
docker run -p 8000:8000 chromadb/chroma

Terminal 2: Backend
cd resume-screening-backend
npm run dev

Terminal 3: Frontend
cd resume-screening-frontend
npm run dev


### 2. Open Application

Navigate to `http://localhost:5173`

---

## Usage Walkthrough

### Step 1: Upload Resume

1. Click or drag a resume file (PDF/TXT)
2. See file preview with name and size
3. Remove and re-upload if needed

### Step 2: Upload Job Description

1. Click or drag a job description file
2. Verify both files are uploaded
3. Click "Analyze Match" button

### Step 3: View Analysis

**Match Score**
- Circular progress shows percentage
- Animated count-up effect
- Green accent for visual appeal

**Strengths**
- Bulleted list with checkmark icons
- Highlights matching qualifications
- Extracted from both documents

**Gaps**
- Bulleted list with X icons
- Shows missing requirements
- Helps identify training needs

**Overall Assessment**
- 2-3 sentence summary
- Generated by Groq LLM
- Contextual evaluation

### Step 4: Ask Questions

**Sample Questions:**
- "Does this candidate have a degree from a state university?"
- "What is their experience with React and Node.js?"
- "Can they lead a backend development team?"
- "Do they have any cloud platform experience?"

**Chat Features:**
- Context-aware responses
- Conversation history maintained
- Sources cited (resume sections)
- Typing indicators

## Troubleshooting

### Upload Fails
- Check file size (max 5MB)
- Verify file type (PDF or TXT)
- Check backend logs for errors

### Chat Not Responding
- Verify resumeId from upload response
- Check Groq API key in .env
- Ensure ChromaDB is running

### Match Score 0%
- Verify both files uploaded correctly
- Check if text was extracted (backend logs)
- Try with TXT files first

---

## Performance Tips

- Use TXT files for faster parsing
- Keep files under 2MB for best speed
- ChromaDB warm-up on first query (~2s)
- Subsequent queries are instant (<1s)
